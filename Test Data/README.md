# StandHard Dataset Documentation for GIP Testing

This dataset was generated by **StandHard (v1.1)** to test the analysis capabilities of the **GIP** platform. The dataset compares tumor samples with healthy tissue samples.

---

## 1. General Dataset Overview

* **Data Origin**: Combined from **GTEx v11** (healthy tissues) and **GDC Data Release 46.0** (tumor tissues).
* **Total Samples**: 40 samples divided into two balanced groups:
  * **20 Osteosarcoma samples** (from GDC: bones, joints, and articular cartilage of limbs).
  * **20 Healthy Skeletal Cell samples** (from GTEx v11: *Muscle - Skeletal* tissue).
* **Total Genes**: 55,751 analyzed genes (e.g., `ENSG00000000003`).
* **Creation Date**: October 9, 2026.

---

## 2. Description of Individual Files

### 📄 `manifest.json`
The primary metadata file describing the overall configuration and Quality Control (QC) outcomes.
* **Contents**:
  * Program information and database versions used.
  * Group selection filters and parameters (Osteosarcoma vs. Healthy).
  * SHA256 hashes and file sizes for data integrity verification.
  * **Quality Control (QC) Results** and detailed variability factors.
  * Runtime environment specifications (Python 3.13.3, pandas 2.3.3, numpy 2.2.6).
  * Mapping of all 40 samples (`sample_id` from `S1` to `S40`) with their respective original barcodes and file IDs.

---

### 📊 `counts_matrix_unito.tsv`
The **RNA-Seq gene expression count matrix**.
* **Contents**:
  * Formatted as a TSV (*Tab-Separated Values*) file.
  * **Rows**: Genes identified by Ensembl IDs (e.g., `ENSG00000000003`).
  * **Columns**: The 40 samples labeled `S1` through `S40`.
  * **Values**: Raw read counts of gene expression for each gene across every sample.

---

### 📋 `metadata_unito.tsv`
Contains clinical, demographic, and technical metadata linked to each sample.
* **Contents**:
  * A TSV table where each row corresponds to one sample (`S1`–`S40`).
  * Annotation fields including:
    * Condition (`Osteosarcoma` vs. `Cellule scheletriche sane`).
    * Source project (`GDC` or `GTEx`).
    * Demographic data (Age, Sex, Ethnicity).
    * Quality and sample preparation parameters (RIN, ischemia time, Hardy death classification, RNA isolation/expression batches).

---

### ⚠️ `qc_fattori.tsv` (Quality Control Factors Table)
Analyzes potential **confounding variables (batch effects and clinical confounders)**.

#### QC Status: **`CRITICAL`**
The automated assessment highlights that downstream Differential Expression Analysis (DEA) is heavily confounded by **batch effects** and overlapping variables:

| Factor | Explained Variance (%) | Risk Level | Notes / Guidance |
| :--- | :---: | :---: | :--- |
| **Condition** | 82.65% | `CONDITION` | Primary biological signal. |
| **Dataset Origin** | 82.65% | `CRITICAL` | 100% overlap with condition (GDC = Tumor, GTEx = Healthy). Impossible to separate biology from platform bias. |
| **Project (GDC)** | 82.65% | `CRITICAL` | Same issue as Dataset Origin. |
| **Organ / Primary Site** | 82.65% | `CRITICAL` | Overlaps completely with condition. |
| **Age** | 72.33% | `CRITICAL` | High correlation with condition (87%). |
| **Death Type (Hardy)** | 47.13% | `CRITICAL` | Explains high variance; requires batch correction or inclusion as a covariate in the model. |
| **Sex, RIN, Ischemia, Ethnicity** | < 11% | `LOW` | No critical issues detected. |

> 📌 **Key Warning**: Because tumor data (GDC) and healthy data (GTEx) were sequenced and processed using different pipelines, observed expression differences are highly likely to reflect **batch effects** rather than true tumor biology.

---

## 3. Dataset Purpose

The data in this set was **intentionally designed with critical confounding factors**. This setup serves to demonstrate and showcase **StandHard's** capability to automatically detect and flag potential **batch effects** and methodological flaws in biological data before running downstream analyses.
